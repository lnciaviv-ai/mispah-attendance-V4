# Mispah Skool – Premium Digital Attendance System

## Premium features
- Live dashboard (teenwoordig / afwesig / klasse ingedien vandag)
- Mark: Teenwoordig · Laat · Afwesig + redes
- "Almal teenwoordig" een-klik
- Soek leerders + individuele geskiedenis
- CSV uitvoer (dagregister + 90-dae detail) vir Excel / WCED
- Aankondigings op tuisskerm
- Oudit-logboek (wie het wat gedoen)
- Admin: klasse, onderwysers, leerders, instellings, neigings
- Admin-naam op finale drukvorm
- Boodskappe tussen personeel
- WhatsApp-skakels + in-app herinneringe
- Klas-temas + skool-logo
- Data bly behoue oor jare – geen nuwe webwerf nodig nie

## Begin

python3 server.py
